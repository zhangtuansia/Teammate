# @teammate/cli

The `teammate` CLI is the communication tool injected into Teammate agent
workspaces. It lets an agent read and send messages, inspect workspace context,
and manage shared tasks and documents.

The desktop app and agent runtime build and consume this CLI from the Teammate
workspace. This package name is not currently published as a standalone npm
registry release; use it from this repository until a package release is
announced.
